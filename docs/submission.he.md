# בקרות נתונים – דף הגשה

מבחן Fullstack: מערכת בקרות נתונים דינאמית (PYTHON, ‎.NET, Angular, SQL Server).

## מה המערכת

מערכת גנרית להגדרת בקרות איכות נתונים, להרצתן ולניתוח החריגות. הגדרת בקרה נעשית בממשק בעברית, מתוך מונחים
עסקיים בלבד: בלי SQL, בלי שמות טבלאות ובלי שמות שדות. המערכת מתרגמת את ההגדרה לשאילתה אחת עם פרמטרים, מריצה
אותה בהרשאת קריאה בלבד, ומציגה את הרשומות החריגות ואת הסיבה לכל חריגה.

בקרה חדשה היא נתון ולא קוד: אין שאילתה קבועה לבקרה ואין פיתוח ייעודי לבקרה. הוספת שדה, ישות או קשר היא עריכה
של קובץ אחד, מילון המונחים העסקי.

## הרצה

עם Docker, מתוך תיקיית המאגר (ההרצה הראשונה אורכת כמה דקות):

| מערכת הפעלה | פקודה |
|---|---|
| Windows | <span dir="ltr">`start.cmd`</span> |
| Linux, macOS, WSL | <span dir="ltr">`scripts/start.sh`</span> |

בסיום ההרצה המערכת זמינה בדפדפן בכתובת <span dir="ltr">http://localhost:5000</span>, וברשימה שש בקרות לדוגמה מוכנות להרצה.

הרצה בלי Docker, מול SQL Server מקומי, והוראות ההתקנה המלאות: [README](../README.md) (באנגלית).

## ארבע הדוגמאות שבמטלה

ארבע הבקרות שהמטלה מביאה כדוגמה מוגדרות במערכת ונטענות בהרצה הראשונה, יחד עם שתי בקרות נוספות.

| הדוגמה במטלה | שם הבקרה במערכת | חריגות בנתוני הדוגמה |
|---|---|---|
| איתור עובדים שגילם נמוך מ־18 ושכרם גבוה מ־15,000 ש"ח | קטינים בשכר גבוה | 3 |
| איתור עובדים שתאריך סיום העסקתם מוקדם מתאריך תחילת העסקתם | סיום העסקה לפני תחילתה | 3 |
| איתור עובדים פעילים המשויכים למחלקה שאינה פעילה | עובדים פעילים במחלקה לא פעילה | 6 |
| איתור רשומות שבהן חסרים נתונים המחויבים לפי כללים עסקיים | נתוני חובה חסרים | 10 |

שתי הבקרות הנוספות: "מחלקות פעילות ללא עובדים פעילים" (3 חריגות) ו"חריגות שכר במשרד לא פעיל" (3 חריגות).

## המשימה המתקדמת

תכנון היכולת שבה AI מנתח את מבנה בסיס הנתונים ומציע בקרות באופן יזום מופיע בפרק <span dir="ltr">"The optional task"</span> של המסמך
[summarize-architecture.md](summarize-architecture.md). תוכנית העבודה למימוש:
[dev/active/dc-ai-suggestions/plan.md](../dev/active/dc-ai-suggestions/plan.md). במערכת עצמה קיימות כבר היום הצעות
לבקרות ללא מודל שפה: המנוע גוזר אותן ממילון המונחים ומפרופיל הנתונים.
